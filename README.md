# NORTHMEN

Демонстрационный сайт вымышленного барбершопа. Учебный коммерческий макет для портфолио: цены, мастера, адрес, телефон и отзывы не относятся к реальному заведению.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Стек: React, TypeScript, Vite. Отдельных UI-библиотек нет.
